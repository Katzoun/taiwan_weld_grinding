# PointNet segmentation. Pin <2.16: TF 2.16+ defaults to Keras 3, whose .h5 loader
# can't deserialize this model's legacy TensorFlowOpLayer (raw TF ops embedded in
# a functional-API graph, common in ~2020-2021-era PointNet Keras code) --
# ValueError: Unknown layer: 'TensorFlowOpLayer'. TF <2.16 bundles Keras 2, which
# still understands it.

# --tf_xla_auto_jit=0, tf.config.optimizer.set_jit(False)) *before* Open3D is
# imported anywhere in the process. GPU inference fails on this machine (CUDA
# toolkit component mismatch -> "libdevice not found", JIT compilation failed on
# BatchNormalization's Rsqrt op) regardless of those flags if Open3D's CUDA-context
# init has already happened -- CPU inference works reliably and is fast enough
